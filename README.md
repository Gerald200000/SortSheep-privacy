# Sort the Sheep – Privacy Policy

The privacy policy for **Sort the Sheep**, a colour-sorting puzzle game for Android by PureForm Solutions.

The policy is in [`index.html`](index.html). Once GitHub Pages is switched on for this repository, it is published at:

**https://gerald200000.github.io/SortSheep-privacy/**

Use that link as the privacy policy URL in the Google Play Console.

When the app changes how it handles data (for example, adding analytics or another ad network), update `index.html` and its "Last updated" date.
